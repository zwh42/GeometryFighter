# Geometry Fighter

当前发布版本：1.7.1

一款为微信小游戏打造的竖屏单手霓虹生存射击游戏。**1.7.0 起完全运行在自研的零依赖 WebGL 渲染器上**（Cocos Creator 已移除）。目标是复现经典街机式几何战斗的核心感受：在不断升级的封闭网格中移动、沿手势方向持续射击、维持倍率并追逐高分。

## 性能架构（1.7.0 重写）

- **自研 WebGL 矢量渲染器**：网格、粒子、敌人、弹道、特效全部直接写入一块预分配的顶点缓冲，整帧战斗几何一次 `drawArrays` 上传，暖机后零 GC 分配——这是消除“几分钟后卡顿”的根本手段（旧版 Cocos Graphics 每帧对数千条线段重新做 CPU 曲面细分）。
- HUD 文字走离屏 2D 画布栅格化纹理，仅在文本变化时重绘；最高分只在破纪录时节流写本地存储，不再出现每帧同步读取。
- 微信主包从约 5 MB 引擎包缩到约 150 KB。
- 三档自适应画质（粒子预算 640/448/256 + 辉光层逐级收缩）保持不变。

## 已实现

- 竖屏单手：下半屏浮动摇杆控制移动与自动射击；回中保持最后方向，松手停火
- 触屏浮动方向控制，以及 Web 预览键鼠控制
- 7 类程序化几何敌人：漂移体、追踪体、织行体、旋翼体、长蛇、排斥体、黑洞；织行体会侧闪躲避弹道，黑洞会吞噬敌人增值并在临界质量爆发成追踪体环
- 倍率晶体经济：击杀掉落晶体，靠近自动磁吸收集，每 6 颗倍率 +1 至上限 ×25，死亡清零；连锁引爆不掉晶体
- 敌人批次、难度升级、武器升级；生成点强制距玩家至少 250 单位
- 3 条初始生命；75,000 分奖励生命
- 超级补给：每 12–18 秒首次出现，之后每 18–28 秒出现，100,000 分里程碑也会追加；命中 8 次后随机触发连锁引爆、8 秒九向火力过载或 12 秒僚机编队
- 首次命中旋翼体可触发 5 秒追踪导弹模式：**全新导弹剪影**——细长弹体、圆润鼻锥、后掠尾翼、闪烁尾焰与渐隐烟迹
- 弹簧质点动态网格：欠阻尼回弹，响应爆炸涟漪、黑洞下陷、玩家船体挤压、每颗子弹的犁痕与重生冲击波
- 程序化霓虹轮廓、弹道、拖尾、按敌型加权的双色粒子爆炸、死亡慢动作与白闪、屏幕震动与自适应画质分层（粒子预算与辉光逐级收缩保帧率）
- 5 首内置背景音乐每次启动随机选择，并每 60 秒无重复切换；WebAudio 合成射击、爆炸和奖励音效
- 本地最高分存储，失焦自动暂停

精髓调研与逐项落地对照见 [GEOMETRY-WARS-ESSENCE.md](GEOMETRY-WARS-ESSENCE.md)。

## 操作

- 触屏：下半屏单指拖动移动并沿拖动方向持续射击，回中保持方向，松手停火
- Web 预览：鼠标拖动等同触摸；`WASD` 移动，`IJKL` 射击，`P` 暂停，回车开始
- Web 预览美术巡检：`index.html?demo=play` 自动战斗，`?demo=missile` 常驻导弹模式（微信包内不生效）

## 运行

1. 执行 `npm run build:wechat` 构建发布包（纯 Node + tsc，无需 Cocos Creator）。
2. 微信开发者工具选择“小游戏”并导入 `build/wechat-1-7-1`。
3. 使用默认竖屏模拟器编译运行。
4. 首次触摸后音频解锁。
5. 浏览器直接打开 `build/web-preview/index.html` 即可试玩同一份构建。

无需安装运行时依赖。首次进行本地验证时先安装开发依赖：

```bash
npm install
```

随后执行纯逻辑测试、JavaScript 语法检查和 TypeScript 类型检查：

```bash
npm test
npm run check
```

构建微信小游戏发布包与浏览器预览包（默认输出 `build/wechat-1-7-1` 和 `build/web-preview`）：

```bash
npm run build:wechat
```
