# Geometry Fighter

当前发布版本：1.6.5

一款为微信小游戏从零实现的竖屏单手霓虹生存射击游戏。目标是复现经典街机式几何战斗的核心感受：在不断升级的封闭网格中移动、沿手势方向持续射击、维持倍率并追逐高分。

## 已实现

- 竖屏单手：下半屏浮动摇杆控制移动与自动射击；回中保持最后方向，松手停火
- 触屏中央智能炸弹，以及模拟器键盘控制
- 7 类程序化几何敌人：漂移体、追踪体、织行体、旋翼体、长蛇、排斥体、黑洞
- 敌人批次、难度升级、武器升级、1–10 倍计分倍率
- 3 条初始生命、3 枚初始智能炸弹；75,000 分奖励生命
- 超级补给：每 12–18 秒首次出现，之后每 18–28 秒出现，100,000 分里程碑也会追加；命中 8 次后随机触发连锁引爆、8 秒九向火力过载或 12 秒僚机编队
- 首次命中旋翼体可触发 5 秒追踪导弹模式
- 会被冲击波和黑洞扭曲的动态网格
- 程序化霓虹轮廓、弹道、拖尾、粒子爆炸、屏幕闪光与震动
- 5 首内置背景音乐每次启动随机选择，并每 60 秒无重复切换；WebAudio 合成射击、爆炸和奖励音效
- 本地最高分存储，失焦自动暂停

## 操作

- 触屏：下半屏单指拖动移动并沿拖动方向持续射击，回中保持方向，松手停火；右下角点击 `BOMB`
- 开发者工具键盘：`WASD` 移动，`IJKL` 射击，空格炸弹，`P` 暂停，回车开始

## 运行

1. 先执行下方“构建微信小游戏发布包”中的 `npm run build:wechat`。
2. 微信开发者工具选择“小游戏”并导入 `build/wechat-v1-6-5`。
3. 使用默认竖屏模拟器编译运行。
4. 首次触摸后音频解锁。

无需安装运行时依赖。首次进行本地验证时先安装开发依赖：

```bash
npm install
```

随后执行纯逻辑测试、JavaScript 语法检查和 TypeScript 类型检查：

```bash
npm test
npm run check
```

构建微信小游戏发布包（默认输出 `build/wechat-v1-6-5`）：

```bash
npm run build:wechat
```
