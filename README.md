# Geometry Fighter

一款为微信小游戏从零实现的竖屏单手霓虹生存射击游戏。目标是复现经典街机式几何战斗的核心感受：在不断升级的封闭网格中移动、沿手势方向扇区持续射击、维持倍率并追逐高分。

## 已实现

- 竖屏单手：下半屏浮动摇杆控制移动与方向扇区；回到中心可停步并沿记忆方向继续射击
- 默认子弹只在出膛时对前方窄扇区做一次落点修正，飞行中保持直线，不会自动追踪
- 无炸弹库存或副按钮；超级武器全部由可击破补给触发
- 12 类程序化几何敌人：漂移体、追踪体、织行体、旋翼体、长蛇、排斥体、黑洞、冲锋体、环绕体、重甲体、分裂体与碎片
- 18 秒 Assault 波次在 SWARM、FLANK、SPIRAL、SIEGE 四种敌潮规则间轮换，波末提供 2.5 秒停止增援的喘息窗口
- 同一批敌人会沿同侧分列锁定并以细线预警环入场；难度、武器与 1–10 倍计分倍率随生存进度升级
- 首次击中旋翼体会启用 5 秒自动循迹导弹，导弹会平滑转向追击目标
- 随机刷新需要 8 次命中的超级武器补给，效果为全屏连锁自爆、8 秒过载弹幕或 3–5 架自动攻击的友军战机
- 3 条初始生命；75,000 分奖励生命，100,000 分提前投放超级武器补给
- 会被冲击波和黑洞扭曲的动态网格
- 程序化霓虹轮廓、弹道、拖尾、粒子爆炸、屏幕闪光与震动
- WebAudio 合成射击、爆炸和奖励音效；音乐分包加载后，每次启动从五首背景音乐中随机选择并循环播放，敌潮生成对齐当前曲目的节拍
- 本地最高分存储，失焦自动暂停

## 操作

- 触屏：下半屏单指拖动移动并确定射击扇区；保持触摸并回到摇杆中心可停步射击；松手停止开火；连续命中补给即可自动释放超级武器
- 开发者工具键盘：`WASD` 移动，`IJKL` 射击，`P` 暂停，回车开始

## 运行

1. 微信开发者工具选择“小游戏”并导入本目录。
2. 使用竖屏模拟器编译运行。
3. 首次触摸后音频解锁。

无需安装运行时依赖。首次进行本地验证时先安装开发依赖：

```bash
npm install
```

随后执行纯逻辑测试、JavaScript 语法检查和 TypeScript 类型检查：

```bash
npm test
npm run check
```

## 调试接口

开发者工具控制台可通过 `GameGlobal.geometryGame` 获取当前实例：

```js
GameGlobal.geometryGame.debugSnapshot()
GameGlobal.geometryGame.debugStart()
GameGlobal.geometryGame.debugSpawn('blackhole', 1)
GameGlobal.geometryGame.debugLoseLife()
```

`debugSnapshot()` 的 `assault` 字段可查看当前波次名称和剩余秒数。
