## Visual direction

- Core metaphor: a cyan-white triangular fighter piercing a lime hexagonal energy core while geometric threats close in.
- Palette: `#01040c`, `#42efff`, `#b9ff36`, `#ff48ed`, `#476dff`, `#f7ffff`.
- Identity rules: strong silhouette, readable at small sizes, restrained neon bloom, reactive grid depth, and distinct threat geometry.
- Avoid: phone frames, pasted HUDs, generic lightning marks, unrelated symbols, rainbow neon, and crowded UI.
